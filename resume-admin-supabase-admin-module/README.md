# Resume Builder Pro - Supabase SEO Blog Admin Module

This ZIP contains a drop-in JavaScript admin module for a Next.js App Router project.

## Features

- Admin login
- Blog post list table
- Create, edit, delete posts
- Draft/published status
- SEO title and description
- Focus keyword
- Canonical URL
- Cover image and alt text
- Tags and categories
- Block-based content editor
- Blog listing page
- Blog detail page
- Table of contents
- Article JSON-LD schema
- FAQ JSON-LD schema
- Sitemap and robots routes
- Supabase PostgreSQL schema

See `docs/INSTALL.md` for setup.
